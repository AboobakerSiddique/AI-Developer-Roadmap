# 🤖 AI Email Generator

A Python-based AI application that generates professional emails
using Google's Gemini API.

## 🎯 Purpose

This project was built while studying Prompt Engineering.

It demonstrates how to combine Python application logic,
prompt templates, structured LLM output, validation,
error handling, and basic AI evaluation.

## 🧠 Concepts Learned

- Prompt structure
- Role prompting
- Context
- Constraints
- Delimiters
- Prompt templates
- Zero-shot prompting
- Iterative prompting
- Structured output
- Input validation
- JSON parsing
- API error handling
- Prompt injection awareness
- LLM evaluation

## 🏗️ Architecture

User
↓
Python Input
↓
Validation
↓
Prompt Template
↓
Gemini API
↓
Structured JSON
↓
Response Validation
↓
Generated Email

## ✨ Features

- Formal emails
- Friendly emails
- Concise emails
- Apologetic emails
- Dynamic key points
- Structured subject + body output
- Input validation
- API error handling
- Basic evaluation

## 🛠️ Tech Stack

- Python
- Google Gemini API
